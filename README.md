🛍️ E-Commerce MERN Stack Application with Admin Panel
A full-featured e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). This app provides both customer-facing features and a secure admin panel for managing products, users, and orders.

🧰 Tech Stack
Frontend: React.js, Redux Toolkit, Bootstrap 5

Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Authentication: JWT (JSON Web Tokens)
✨ Key Features
🛍️ User Side (Customer)
User registration and login (JWT-based authentication)

Browse all products

View products by category and brand

Search and filter functionality

Product detail view

Add to cart & update quantities

Simulated checkout flow (PayPal-style)

Order success confirmation

View past orders

👨‍💼 Admin Panel
Admin login

View dashboard overview

Create, update, and delete products

Add/manage categories and brands

Manage all user orders

View registered users

Stock and inventory management

Update order delivery status
